# 📖 Overview

The **Ideal Commerce College Website** is a modern, responsive and scalable MERN Stack web application designed to digitize academic and administrative activities.

The project includes:

- 🌐 Public Website
- 🎓 Student Portal
- 👨‍🏫 Teacher Portal
- 🛠 Admin Dashboard
- 📰 Notice Management
- 📄 Academic Management
- 🖼 Gallery Management
- 📝 Online Admission
- 📊 Student Result System
